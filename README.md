# Aura Coach ✨ — AI Personal Coaching Platform

 Built by **Noi Tech Innovation**

Aura Coach is an AI-powered platform that provides personalized coaching through real-time chat with Google Gemini, helping users track skills and achieve goals.

![Status](https://img.shields.io/badge/status-WIP-yellow)
![Stack](https://img.shields.io/badge/stack-React%20%7C%20Gemini%20%7C%20Firebase-blue)

### 🚀 Features
- **AI Coach Chat:** Real-time conversational coaching with Gemini AI
- **Skill Tracking:** Visual progress bars and growth tracking
- **Secure Auth:** Firebase Authentication
- **Modern UI:** Fast, responsive design with Tailwind CSS

### 🛠️ Tech Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Firebase, Firestore
- **AI:** Google Gemini (`@google/genai`)
- **Build Tool:** AI Studio
